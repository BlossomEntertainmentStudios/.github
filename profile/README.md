# Blossom Projects

A collection of Minecraft-related tools, libraries, and infrastructure powering the **Bloom Client** ecosystem.

## What we do

We develop and maintain open-source software for Minecraft modding, client development, and server tooling — ranging from Gradle plugins and audio libraries to backend services and shader compilation.

## Key projects

| Project | Description |
|---|---|
| [BlossomClient](https://github.com/BlossomProjects/BlossomClient) | Minecraft hacked client using Mod Coder Pack |
| [BloomGradle](https://github.com/BlossomProjects/BloomGradle) | Gradle toolchain for Bloom Client |
| [BloomEvent](https://github.com/BlossomProjects/BloomEvent) | Lightweight Kotlin-first event bus |
| [BloomAudio](https://github.com/BlossomProjects/BloomAudio) | Kotlin audio library built on OpenAL |
| [shader-compiler](https://github.com/BlossomProjects/shader-compiler) | Minecraft shader pack compiler |
| [NativeGradle](https://github.com/BlossomProjects/NativeGradle) | Gradle plugin for Go + JNI |
| [mirakle](https://github.com/BlossomProjects/mirakle) | Distributed remote Gradle builds |
| [backend](https://github.com/BlossomProjects/backend) | Bloom Client backend API |
| [config.bloomproject.lol](https://github.com/BlossomProjects/config.bloomproject.lol) | Web-based Bloom config system |

## Tech stack

**Kotlin**, **Java**, **Go**, **Python**, **C3**, **Svelte**, **Node.js**
