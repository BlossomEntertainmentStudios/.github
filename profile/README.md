# Blossom Entertainment Studios

**Minecraft client engineering, developer tooling, and backend infrastructure.**

We build the **Bloom Client** ecosystem: a Minecraft 1.8.9 client, the libraries and build tooling around it, and the services that keep it running. Our work spans Kotlin and Java on the client, Go on the backend, and native tooling for graphics, shaders, and build automation.

> Most of our repositories are private. Public projects are available in the [repositories tab](https://github.com/orgs/BlossomEntertainmentStudios/repositories).
