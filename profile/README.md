# Blossom Projects

A collection of Minecraft-related tools, libraries, and infrastructure powering the **Bloom Client** ecosystem.

## What we do

We develop and maintain open-source software for Minecraft modding, client development, and server tooling — ranging from Gradle plugins and audio libraries to backend services and shader compilation.

## Tech stack

**Kotlin**, **Java**, **Go**, **Python**, **C3**, **Svelte**, **Node.js**
